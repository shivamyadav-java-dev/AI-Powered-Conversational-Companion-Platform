## Technologies Used

### Frontend
- React.js
- Vite
- Tailwind CSS
- shadcn/ui

### Backend
- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- MySQL

## Getting Started

### Frontend Setup

cd Frontend
npm install
npm run dev

### Backend Setup

Open the Backend folder in IntelliJ IDEA.

Configure your database and application properties.

Run the Spring Boot application.

- User Authentication
